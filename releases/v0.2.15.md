# N-Lite v0.2.15

Fix automatic standby cleaning feedback and startup controls.

- Show automatic clean results as Windows tray notifications while N-Lite is hidden.
- Report the helper's exact automatic-clean before/after measurements in the tray, so unrelated standby changes cannot show a false result. Failed or ineffective attempts stay armed and retry after the configured interval.
- Keep disabled user-owned scheduled startup tasks toggleable. Re-enabling a task also re-enables its disabled sign-in or boot trigger.
- Exercise startup controls through their rendered UI hit targets, including toggle, delete, add and refresh.
- Verify startup-task changes and automatic cleaner retries in Windows tests.

The protected cleaner helper is version 5. Updating it during installation may request one administrator approval; routine cleaning and toggle use continue through the existing SYSTEM task without elevation.
