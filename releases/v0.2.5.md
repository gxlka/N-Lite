## What's new

- Fixed timer resolution dragging so the slider follows the pointer and stays within the Windows-supported range.
- Reworked Startup to list current-user and all-users Run, RunOnce, and Startup folder entries.
- Added enable/disable controls for current-user startup entries and an option to add apps for the current Windows account.
- Moved N-Lite's own launch-with-Windows switch to Settings.

All-users startup entries are shown as read-only. Managing them remains in Windows because it can require administrator access.
