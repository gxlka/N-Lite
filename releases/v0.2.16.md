## Fixed
- Automatic standby cleaning stays enabled after a purge and repeats at the saved interval while standby remains above the threshold.
- The cleaner status now explains whether it is waiting for the threshold, waiting for the next interval, or ready for its next scheduled check.
- Automatic cleans no longer show tray balloons. Manual Clean Now still reports success or failure.
- Startup task controls now reflect the current user's actual Windows file permissions. Tasks the app cannot edit or delete are read-only.
- Startup-folder shortcuts marked read-only can still be disabled, re-enabled, or deleted.
- A denied Startup action disables that control until the list is refreshed.
