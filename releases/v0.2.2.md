# N-Lite v0.2.2 — Full release notes

This release includes the complete N-Lite feature set from the first public build and the fixes and updater changes delivered since then.

## Full feature set

### Memory

- Live RAM, available-memory and free-memory readings, plus standby-list size, system commit and page-file usage.
- Manual standby-list purge and automatic purge controlled by an editable memory threshold and a saved check interval.
- The scheduled cleaner reports success or a Windows permission failure. Windows may require one-time administrator approval when automatic cleaning is configured.
- Timer-resolution setting follows the range reported by Windows, persists across restarts and is released when N-Lite exits.

### Processes

- Searchable, sortable process list with executable icons, PID, CPU, working-set memory and private-memory columns.
- Collapsed executable groups show the total memory used by their listed processes. Expanding a group keeps the individual rows aligned with the group and reports each process's own usage.
- Context menu actions for ending a process, opening its file location, setting priority, CPU affinity and GPU preference.
- Saved priority and CPU-affinity choices are reapplied to later instances of the same executable; GPU preference is stored for the current Windows user.
- Windows permissions still govern actions on protected or elevated processes.

### Window, tray and startup

- Native x64 Win32 app with a large, movable and resizable window, plus notification-area access after closing or minimizing.
- Optional per-user launch at sign-in and an optional desktop shortcut.
- Per-user installation under %LOCALAPPDATA%/Programs/N-Lite; a portable executable is published too.

## Changes since the first release

- Fixed the main content layout so panels use the available window width with even side margins instead of leaving large empty gutters.
- Kept process expansion anchored to the selected group so expanded rows remain beside the group that was opened.
- Made collapsed process totals use the aggregate working set and private memory of the matching process instances.
- Improved standby-cleaner completion and denial reporting so a successful or blocked Windows purge is visible.
- Replaced the update button's GitHub-page redirect with an in-app installer flow. When a newer release is available, Install update downloads the per-user setup package, checks its SHA-256 digest against the GitHub release asset metadata, runs setup silently, closes N-Lite for replacement, and relaunches the updated app.
- Expanded these release notes with the full feature list and the changes since the first published build.

## Updating from older builds

Builds that predate this updater still send users to the GitHub release page. Install v0.2.2 once using the setup package below; future update buttons can download and install newer releases inside N-Lite.

## Requirements

Windows 10 version 1809 (build 17763) or later, x64. N-Lite is a tray application, not a Windows service.
