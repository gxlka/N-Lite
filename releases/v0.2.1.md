# N-Lite v0.2.1 — First public release

N-Lite is a native 64-bit Windows utility for checking memory and managing running processes from one resizable desktop window. It can stay available from the notification area when the window is closed.

## What is included

### Memory and standby list

- Live memory view for installed RAM, available memory, free memory, standby-list size, system commit and page-file use.
- Manual standby-list purge.
- Automatic standby cleaning with an editable MB threshold and a saved check interval.
- Automatic purging uses a Windows scheduled task with the privileges required by Windows to request a standby-list purge. The app reports whether the request completed or Windows denied it.
- Timer-resolution controls use the range reported by the current Windows installation. The selected setting is saved and re-applied when N-Lite starts; N-Lite releases its timer request when it exits.

### Processes

- Searchable, sortable process list with application icons, process IDs, CPU activity, working-set memory and private memory.
- Related processes are grouped by executable. A collapsed group shows the summed memory for the listed members; expanding it shows the individual process rows and their own usage.
- Context actions include ending a process, opening its file location, setting priority, choosing CPU affinity, and selecting a GPU preference.
- Priority and CPU-affinity choices are saved per executable and reapplied to later instances. GPU preference is saved in the current Windows user profile.
- Process actions remain subject to the permissions Windows grants N-Lite for the selected process.

### Startup, settings and installation

- Optional per-user startup in the notification area and an optional desktop shortcut.
- Settings page with the installed version and an update check that runs at launch and periodically.
- The x64 setup installs per-user under %LOCALAPPDATA%/Programs/N-Lite; administrator rights are not required for the normal installation.
- A portable N-Lite.exe is also published with the setup package.

## Requirements and notes

- Windows 10 version 1809 (build 17763) or later, x64.
- N-Lite is a tray application, not a Windows service.
- Windows protects standby-list purging. Turning on automatic purging may require approving the scheduled-task setup once; if Windows denies a purge, the app shows that result.

This is the first public release. Later release notes record changes made after this baseline.
