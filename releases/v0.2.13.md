## What's fixed

- Auto clean reuses the existing SYSTEM scheduled task after restarting N-Lite or Windows, including when the packaged cleaner helper version differs.
- N-Lite checks the installed task's account, action, helper path, and run permissions before starting it. It only requests elevation when a usable SYSTEM task is missing.
- Canceling initial task setup is remembered, so toggling Auto clean does not reopen UAC on every press.

If no usable SYSTEM task has been installed, the first cleaner setup still needs one administrator approval. Later auto-clean toggles run through Task Scheduler without UAC.
