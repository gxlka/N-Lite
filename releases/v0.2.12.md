## What's fixed

- Standby no longer displays a failed query as `0`; it retries Windows buffer-size failures and reads a fresh sample from the SYSTEM cleaner when the app's own query is unavailable.
- Clean results compare the SYSTEM cleaner's standby size before and after the purge.
- Auto clean remembers a canceled or failed setup, so toggling it no longer repeats UAC. Use Clean now to retry setup; an existing cleaner upgrade may request one UAC approval.
- Startup now includes Windows boot and sign-in scheduled tasks and enforced startup entries, labels disabled entries accurately, and has larger switches plus a delete icon for entries owned by your account.
