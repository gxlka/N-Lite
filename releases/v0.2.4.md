# N-Lite v0.2.4

## Standby cleaner

- Fixed scheduled task verification so Windows-normalized security descriptors are accepted. Cleaner setup no longer repeats the UAC prompt because ACE rights or trustee names were reordered during verification.
- Corrected standby memory accounting to read the fixed-width Windows memory-list structure and total all eight standby priority buckets. Automatic cleaning remains enabled after an unsuccessful setup attempt.

## Interface and installer

- Added the N-Lite icon to the app window, executable, tray, installer, and shortcuts.
- Simplified the process right-click menu to Open file location and End task, removing priority, CPU affinity, GPU preference, and the selected-option checkmark.
- Added Restart Manager close handling so Inno Setup can close N-Lite during installation while ordinary window close continues to minimize to the tray.

Windows 10 version 1809 (build 17763) or later, x64.
