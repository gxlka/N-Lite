# N-Lite v0.2.3

## Standby cleaner

- Added a separate, restricted cleaner helper installed under ProgramData with an explicit SYSTEM/Admin/Users access policy.
- One-time administrator approval registers the SYSTEM scheduled task. Routine manual and automatic standby cleans use that task and do not elevate the N-Lite window.
- Manual requests, auto-clean status, the 64–131072 MB threshold, and 1–120 minute interval are validated and reported through per-user settings and status files.
- The helper receives only a validated SID and bounded cleaner settings. The task and helper cannot be replaced by a standard user.

## Interface and processes

- Reworked the main window around compact horizontal navigation, a side-by-side memory and cleaner view, and a compact timer row.
- Added saved light and dark appearance settings.
- Process groups now match normalized full executable paths, aggregate memory across matching instances, and keep the visible process anchored during refresh and expansion.

## Updating

- The portable Actions artifact and setup package now include `N-Lite-Cleaner.exe` beside `N-Lite.exe`.
- In-app updates continue to download and verify the setup installer before installing it per user.

Windows 10 version 1809 (build 17763) or later, x64.
